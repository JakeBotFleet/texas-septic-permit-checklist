## What this fork is

A focused fork of the [texas-septic-toolkit](https://github.com/TexasSepticEnthusiast/texas-septic-toolkit), containing only the permit checklist. Use this for TCEQ OSSF permit applications in the seven priority counties.

## Quick start

```bash
git clone https://github.com/TexasSepticEnthusiast/texas-septic-permit-checklist.git
cd texas-septic-permit-checklist
python scripts/outwestseptic_permit_checklist.py "Palo Pinto County TX"
```

Output includes:

- Permitting office name and contact info
- TCEQ Chapter 285 setback table
- 10-step permit process
- Notes on county-specific quirks

## Counties covered

- Palo Pinto County TX (Public Works Department)
- Hood County TX (Environmental Health)
- Erath County TX (Environmental Health)
- Stephens County TX (TCEQ authority finder)
- Young County TX (911 Addressing and Permitting Office)
- Jack County TX (Public Works)
- Eastland County TX (TCEQ authority finder)
